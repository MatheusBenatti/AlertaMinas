# AlertaMinas — Monitor de Enchentes em Minas Gerais

O **AlertaMinas** é um sistema web desenvolvido com o objetivo de **monitorar riscos de enchentes em municípios do estado de Minas Gerais**, utilizando dados climáticos e simulações de risco.
A aplicação apresenta uma interface interativa com mapa geográfico, indicadores de risco e alertas em tempo real, permitindo visualizar condições climáticas e níveis de rios em diferentes regiões.

---

A aplicação é composta por:

* Mapa interativo com localização dos municípios
* Painel de alertas com informações de risco
* Indicadores climáticos e hidrológicos
* Sistema de fallback para garantir funcionamento mesmo sem resposta da API
